# Verovio Music Notation Engraving Library

- 원문: [Verovio Music Notation Engraving Library](https://www.verovio.org/)
- 관련 기능: MEI 렌더링/변환
- 선별 이유: MEI 중심으로 MusicXML/Humdrum 입력을 받아 SVG로 렌더링하는 오픈소스 라이브러리. 웹 악보 뷰어/하이라이트에 활용.

## 원문 클리핑

## Overview

Verovio is "a music notation engraving library for MEI with MusicXML and Humdrum support" that enables web-based music notation rendering.

## Supported Formats
- **Primary Format**: MEI (Music Encoding Initiative)
- **Input Formats**: MusicXML, Humdrum
- **Output Format**: SVG (scalable vector graphics)

## Development Resources
- JavaScript implementation
- Python implementation

## Key Capability

Verovio converts multiple music notation standards into scalable vector graphics suitable for web applications — a comprehensive solution for digital music notation display and processing. 악보 뷰어에서 note 단위 SVG 요소를 timemap과 연결하면 재생 위치/평가 결과를 하이라이트하는 UI를 만들 수 있다.
