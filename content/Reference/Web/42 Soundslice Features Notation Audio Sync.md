# Soundslice Features Notation Audio Sync

- 원문: [Soundslice Features Notation Audio Sync](https://www.soundslice.com/features/)
- 관련 기능: 악보-오디오/영상 동기화 UX
- 선별 이유: 악보를 실제 녹음/영상과 동기화하고 note highlight·loop·tempo 변경·part 음소거를 제공하는 연습 UX. 정렬 결과 시각화 벤치마크.

## 원문 클리핑

## Core Synchronization

악보를 실제 사람 연주(MP3/영상)와 동기화해 동시 재생. 같은 악보에 여러 연주를 싱크해 해석 비교 가능. syncpoint editor: "Just press Play and tap your keyboard on the downbeats"로 YouTube/MP3와 악보를 정렬.

## Visual Feedback During Playback

재생 중 "notes lighting up visually" — 실시간 score-performance 매핑. "click any note to jump to that moment"로 비선형 탐색.

## Practice-Focused Features

- **Looping**: 음표 위 드래그로 구간 반복(가장 가까운 note/rest/barline에 스냅), "clips"로 구간 북마크
- **Tempo Control**: 피치 변화 없이 느리게 재생
- **Part Management**: 개별 part 숨김/음소거
- **Metronome**: 템포 변화까지 반영한 박자

## Multi-Track

multitrack stems(독립 볼륨), synth overlay(합성음 + 실제 연주 동시 재생).

> 비고: 자동 채점보다 "synchronized practice + note highlight" UX에 강점. 본 앱의 정렬 결과를 악보 위에 어떻게 시각화/탐색하게 할지(note 클릭→해당 시점 이동, 구간 루프)에 대한 UX 레퍼런스. 27번 Soundslice MusicXML import와 짝.
