# AnthemScore Transcribe Web Service

- 원문: [AnthemScore Transcribe Web Service](https://www.lunaverus.com/transcribe/)
- 관련 기능: 오디오/MIDI → 악보 변환(상용)
- 선별 이유: 오디오 또는 MIDI를 PDF/MusicXML/MIDI 악보로 변환하는 상용 AI 서비스. 입력 포맷·다중악기·태블러처 옵션 벤치마크.

## 원문 클리핑

## Core Functionality

"Convert audio or MIDI files into sheet music PDF, MusicXML, and MIDI using AnthemScore AI."

## Supported Input Formats
- MP3, WAV, M4A, FLAC, OGG, MP4, MID
- 업로드(drag-and-drop / 파일 브라우저) 또는 마이크로 직접 녹음 지원

## Output Formats
- Sheet music PDF
- MusicXML
- MIDI

## Advanced Options
- Tablature generation
- Multi-instrument selection

> 비고: 16/17번 AnthemScore 데스크톱 문서와 함께 보면, 사용자가 정확도 슬라이더·악기 선택 등으로 변환 결과를 조정하는 UX 설계의 참고가 된다. audio→악보 방향(2·3번 기능 결합)의 상용 레퍼런스.
