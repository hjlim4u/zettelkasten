# MatchMySound Note Matching Engine

- 원문: [MatchMySound Note Matching Engine](https://www.matchmysound.com/)
- 관련 기능: note-by-note 매칭 피드백 엔진(B2B)
- 선별 이유: note-by-note 매칭 알고리즘으로 pitch/rhythm/tempo 자동 피드백을 주는 B2B 음악교육 엔진. Fender Play·Hal Leonard 등에 탑재.

## 원문 클리핑

## What It Is

음악 교육 기술 플랫폼. "revolutionizing the way music teachers teach and students practice" — guided practice 도구와 라이브 레슨 플랫폼 제공.

## Core Technology: Note-by-Note Matching Algorithm

핵심 차별점은 고유 매칭 기술이다: "our unique note-by-note matching algorithm makes practice productive and learning easier and faster." 학생 연주를 실시간 분석해 여러 음악 차원에서 정밀 평가.

## Automatic Feedback System

세 영역에서 즉시 피드백:
- **Pitch accuracy** — 의도한 음과 일치 여부
- **Rhythm precision** — 타이밍·음 길이
- **Tempo adherence** — 전체 속도 일관성

"record yourself and see exactly where to improve on pitch, rhythm, and tempo."

## Business Model: B2B Engine/SDK

직접 소비자 서비스가 아닌 백엔드 기술 제공자. 탑재 플랫폼: Fender Play, School of Rock, Hal Leonard, Noteflight, Music First, Justin Guitar, Faber Music.

> 비고: 본 앱이 만들려는 "악보 ↔ 연주 비교 후 객관 피드백" 기능의 가장 직접적인 상용 대응물. note-by-note 매칭 = score-performance alignment 기반 채점이라는 설계 방향의 시장 검증 사례. 자체 구현 대 라이선스(B2B 엔진 활용) 판단 근거.
