## 원문 클리핑

## Purpose

The MIDI Association (TMA) produces the technical Specifications that make MIDI products work together. This page is the central hub for those specifications.

## Main Specification Categories

### MIDI 2.0
An extension of MIDI 1.0 built on its core principles. MIDI 2.0 uses MIDI Capability Inquiry (MIDI-CI) to allow devices with bidirectional communication to access extended capabilities while maintaining backward compatibility.

### MIDI 1.0
A foundational protocol first published in 1983, enabling different musical instruments and devices to communicate digitally. Originally used 5-pin DIN connectors and continues to evolve as a core standard.

### MIDI Transports
Specifications for transmitting MIDI data beyond the original 5-pin DIN cable.

### File Formats
- Standard MIDI Files
- DLS (Downloadable Sounds)
- XMF (eXtensible Music Format)
- Mobile MIDI formats
