# Tomplay Korean Blog Six Sheet Music Apps

- 선별 이유: 악보/연습 앱 기능을 한국어로 비교해 사용자 관점 벤치마크에 쓸 수 있다.

개재된 날짜

16/06/2025

기술의 발전과 COVID-19의 영향으로, 우리의 삶 전반의 많은 부분이 디지털화되어가고 있습니다. 음악도 예외는 아니지요. 집안 곳곳에 쌓여 있던 악보 뭉치, 지저분하게 주석을 썼다 지웠다하던 시대는 지나갔습니다. 오늘날에는 많은 음악과 악보 앱들이 여러분이 음악을 배우고 연주하고 정리할 수 있도록 도와드립니다!

이 기사에서는 여섯 가지 음악 앱을 살펴보겠습니다. 그것들이 제공하는 것은 무엇인지와 장단점을 각각 알아보도록 하죠. 그럼 시작해봅시다!

**1\. Tomplay**

![](https://tomplay.com/storage/posts/October2022/EN.png)

가장 먼저 소개해드릴 앱은 당연하게도… [**Tomplay**](https://tomplay.com/kr) 입니다! Tomplay 악보 앱은 [아이패드](https://itunes.apple.com/app/apple-store/id1054809074?pt=1722222&ct=hp-en&mt=8), [아이폰](https://itunes.apple.com/app/apple-store/id1054809074?pt=1722222&ct=hp-en&mt=8), [안드로이드](https://play.google.com/store/apps/details?id=com.tombooks.tomplay), [PC, Mac](https://tomplay.com/kr/get-application) 에서 이용이 가능하며 40,000개 이상의 악보가 있는 방대한 카탈로그를 제공합니다. 클래식 음악부터 팝/록과 재즈 음악까지 폭넓은 장르의 악보들을 25가지 악기 연주에 이용할 수 있으며 악보들은 다양한 연주 난이도를 위해 편곡되었습니다. 전문적인 뮤지션들이 녹음한 반주 트랙도 함께 제공되어 집에서도 편하게 오케스트라나 앙상블에 맞춰 연주할 수 있습니다!

Tomplay 악보 앱은 여러분의 학습을 도울 여러 기능을 제공하는데, 예를 들어 본인의 수준에 맞게 곡의 템포를 조절하거나 자신의 연주를 녹음해 다시 들어볼 수도 있습니다. 또한 특정 구간을 루프로 반복 연습하거나 악보를 읽을 수 없다면 시각적인 보조 도구도 사용할 수 있습니다.

| **장점** | ****단점**** |
| --- | --- |
| - 사용하기 쉽고 이목을 끄는 인터페이스 - 인터랙티브 기능: 악보의 자동 스크롤, 주석을 달고 템포를 조절하며 본인의 연주를 녹음할 수 있음 - 반주: 전문 뮤지션의 고음질 백킹 트랙과 오케스트라 반주 - 폭넓은 악기 선택과 음악 장르 - 대부분의 악보의 난이도 변경이 가능해 모든 사용자들의 접근이 용이함 - 선생님/학생들이 악보, 주석, 녹음을 공유할 수 있음 - 밴드와 앙상블 기능: 그룹에서 연주하거나 앙상블을 가르친다면 유용한 기능 - 악보를 다운로드해 오프라인에서 이용하거나 출력이 가능함 - 14일 무료 체험 - 구매 전에 체험이 가능함! - 모든 장치에서 이용이 가능 | - 어떤 악보는 한 두개의 악기 연주에만 이용이 가능함 - 조옮김 기능이 모든 악보가 아닌 특정 악보에서만 가능함 |

직접 이용해 보길 원하시면, Tomplay는 언제든지 구독 취소가 가능한 14일 무료 체험을 제공합니다.

**2\. forScore**

[**forScore**](https://forscore.co/) 는 iOS 장치에서 독점 이용이 가능한 악보 읽기 앱입니다. 처음 아이패드가 출시되던 2010년에 런칭되었기에 아이패드의 발전에 맞춰 앱이 제공하는 기능도 변화되었습니다. 애플 제품 사용자들에게는 딱 맞는 앱입니다. 이제 모든 연주에 악보 뭉치를 가지고 다니지 않아도 됩니다 - forScore는 본질적으로 뮤지션들을 위한 PDF 리더입니다. 그들이 가진 모든 악보를 한 곳에 모아서 정리하도록 도와주며 상세하게 주석을 다는 것도 가능합니다.

| **장점** | **단점** |
| --- | --- |
| - 매우 사용자 친화적 - 음악을 세트리스트, 작곡가, 태그 등으로 정리가 가능함 - 세트리스트 만들기와 원하는 순서 정렬 선택하기(알파벳 순, 무작위, ‘새로운’ - 오랫동안 연주하지 않은 악보를 보여줌) 등 전문 뮤지션들을 위한 좋은 옵션들 - 다양한 주석 기능(상징, 색깔, 크기), 과 복사/붙여넣기와 강조 기능 - 훌륭한 악보 메타데이터: 곡의 조성, 길이, 아티스트, 평점, 난이도 등 - PDF 옵션: Musicnotes (악보샵)에서 구매한 악보를 가져오거나 종이악보 PDF를 스캔할 수 있음 - 온-스크린 피아노, 튜너, 메트로놈같은 연습 도구 - 다른 뮤지션들과 노트를 공유할 수 있는 공유하기 기능 - €19.99에 단일성 구매, 이후 평생 무료 업데이트 | - 무료 체험이 없음 - iOS에서만 이용이 가능함, 안드로이드 장치에서 이용불가 - 제한된 관리 기능: 악보집 전체를 추가해 원하는 곡으로 넘어가기 위해서는 곡을 일일이 북마크해야함 - 이는 악보 읽기 앱이기 때문에 악보의 조옮김 기능과 같은 몇몇 기능이 제공되지 않음 |

**3\. MuseScore**

저희가 소개하고 싶은 다음 악보 앱은 [**MuseScore**](https://musescore.com/) 입니다. 이 앱은 아이패드, 아이폰, 안드로이드, PC와 Mac에서 제공되는 음악 표기법 앱입니다. 가장 큰 장점은 무료(이자 오픈소스)라는 점입니다. MuseScore는 또한 자체적인 악보 사이트 musescore.com (음악 표기법에 관한 사이트는 musescore.org) 부터 방대한 음악 라이브러리 또한 제공합니다. 라이브러리는 공식 악보와 사용자가 만든 음악 모두를 포함합니다.

| **장점** | **단점** |
| --- | --- |
| - 무료 - 방대한 음악 라이브러리 (대략 140만 개의 악보!) - 사용자들이 음악을 만들고 커뮤니티와 공유해 피드백과 리뷰를 받을 수 있음 - 작업 공간의 표기 요소를 사용자화하여 자신에게 맞는 도구 모음을 만들 수 있음 - 가져오기와 내보내기를 위해 다양하게 지원되는 파일 형식 - 커뮤니티: MuseScore는 오픈 소스이므로 누구나 배포가 가능해 정기적인 업데이트와 악보 추가가 이루어짐 | - 모바일 앱에서의 제한된 옵션: 예를 들어 앱에서는 주석을 달 수 없음 - 음악 라이브러리에서, 대부분의 악보는 사용자가 만든 것이므로 퀄리티를 보장할 수 없음 - 악보 재생기능의 음질이 낮음 - 무료이긴 하지만 제공되는 모든 기능을 이용하려면 구독이 필요함 |

**4\. IMSLP**

Petrucci Music Library (페트루치 음악 라이브러리)로도 알려진 [**International Music Score Library Project (IMSLP)**](https://imslp.org/wiki/Main_Page) 는 퍼블릭 도메인 음악들을 위한 디지털 라이브러리 음악앱입니다. 다시 말하면 저작권이 만료된 음악들, 즉 주로 클래식 음악들을 다룹니다. 이 프로젝트는 2006년에 시작되었고 주된 목표는 퍼블릭 도메인 음악들을 무료로 온라인에서 이용이 가능하도록 하는 것이었습니다. iOS와 안드로이드에서 모두 사용이 가능합니다.

| **장점** | **단점** |
| --- | --- |
| - 현재 630,000개 이상의 악보와 72,000개의 음반을 보유함 - 무료 (그러나, 월간 구독 시 광고가 없고 수 초간 기다리지 않고 악보를 바로 이용할 수 있음) - 클래식 음악가들을 위한 최상의 자원이자 악기, 작곡가, 시대 등의 필터로 정렬할 수 있음 - 초판을 비롯해 다양한 에디션으로 이용 가능한 악보들이 많음 | - IMSLP는 주로 다운로드를 위한 PDF 악보를 제공해 인터랙티브 기능이 없음 - 오직 저작권이 만료된 음악만 다룸 - 라이브러리에 어떤 팝/록 음악도 찾을 수 없음 |

**5\. Piascore**

아이폰과 아이패드 등 iOS 장치에서 이용이 가능한 [**Piascore**](https://apps.apple.com/us/app/piascore-hd/id406141702) 는 무료 악보 읽기 앱입니다. 이 앱은 사용자가 어디서든 악보 이용과 다운로드, 주석과 정리가 가능하게 합니다.

가장 큰 장점 하나는 클라우드 플레이인데, 이는 IMSLP 라이브러리에 있는 수천개의 악보에 대한 이용을 제공합니다. 또한 계정을 드롭박스, 구글 드라이브, 아이클라우드에 연결하여 자신의 PDF 악보들을 동기화할 수 있습니다. 마찬가지로, iTunes에 자신의 계정을 연결하거나, 카메라 캡처 기능을 통해 PDF 악보를 스캔할 수 있습니다.

악보를 추가하고 나면 태그나 세트리스트를 이용해 악보를 정리할 수 있습니다. 필기 기능은 텍스트, 강조, 악상기호 등을 제공합니다. 매트로놈과 튜너같은 연습 도구들도 이용이 가능합니다.

재밌는 사실은 특정 아이폰들에서는 Piascore에서 윙크를 하거나 머리를 흔들어 악보 페이지를 넘길 수 있다는 것입니다. 슬프게도 모두가 이런 기능을 사용할 수 있는 건 아니라고 하네요.

| **장점** | **단점** |
| --- | --- |
| - 인터페이스가 사용하기 쉽고 어떻게 기능들을 사용하는지 앱에서 훌륭한 가이드를 제공함 - 자동 스크롤, 주석, 연습 도구(온-스크린 키보드, 튜너, 메트로놈)등과 같은 유용한 도구들 - 세트리스트나 태그를 사용해 악보를 정리할 수 있음 - 해당 앱은 악보 다운로드 시 자사의 Pia 스토어와 더불어 IMSLP 라이브러리와도 연동되어, 방대한 음악 라이브러리를 제공함. 앱이나 아이클라우드로 PDF 스캔이 가능함 | - iOS에서만 사용 가능 - 주석 기능이 제한됨 - 어떤 디자인 요소들은 시대에 뒤쳐짐 예를 들어 메트로놈 - 앱에서 이용시 커다란 기계식 메트로놈을 페이지 중앙에 보여주어 악보를 가림 - 앱은 무료이지만 녹음이나 온-스크린 키보드와 같이 인-앱 구매를 필요로 하는 몇가지 기능이 있음 |

**6\. Yousician**

[**Yousician**](https://yousician.com/) **은** 다른 앱들과 차별되는 악보 앱입니다. 이 앱은 본질적으로 인터랙티브 학습 앱이며 사용자들에게 어떻게 곡을 연주하는지 가르쳐주고 연주에 대한 피드백을 제공합니다.

현재 피아노, 기타, 베이스, 우쿨렐레와 보컬을 위해 이용이 가능합니다. 처음 로그인하면, 본인의 악기와 능력치를 선택합니다. 각 악기는 다른 테마들로 나뉘어진 몇 개의 레벨이 있습니다. 테마는 곡의 비디오를 포함하는데, 온스크린 악기에 맞춰 연주할 수 있고 음악 이론에 중점을 둔 이론 연습을 할 수도 있습니다. 또한 이 앱은 완료해야 하는 미션을 주어서 새로운 과제를 수행하는데 도움이 됩니다. 이 형식은 거의 게임하는 것과 같이 느껴져서 악기를 시작하는 데는 더 없이 좋은 방법입니다. 이 음악 앱은 아이패드, 아이폰, 안드로이드, PC와 Mac에서 이용이 가능합니다.

| **장점** | **단점** |
| --- | --- |
| - 유익한 레슨 플랜과 튜토리얼 덕분에 초보자에게 좋은 앱 - 사용자들의 학습을 돕기 위해 아주 잘 짜여진 구성. 수많은 온라인 자료들을 수집할 필요없이 Yousician은 쉽고 이해하기 쉬운 종합적인 음악 레슨들을 제공함 - 실시간 피드백! 소프트웨어가 사용자의 연주를 평가해 음정, 리듬, 템포와 기타 요소들에 대한 피드백을 제공함 - 사용자 맞춤형 학습을 제공함 - 목표 트랙커, 연주 통계와 알림 기능 - 선생님과의 레슨을 감당하기 어렵거나 레슨 전에 악기를 먼저 접해보고 싶을 때 최상의 선택 - 무료 체험이 가능함 | - 제한된 악기 선택: 현재 피아노, 기타, 베이스, 우쿨렐레, 보컬을 위한 이용만이 가능함 - 중급 이상의 사용자들에게는 적합하지 않음. 악기에 대한 어느정도 이해를 끝냈다면 Yousician 레슨들이 조금 지루하거나 반복적이며 제한적일 수 있음 - 어떤 사용자들은 정확성에 대한 우려와 의사소통의 부재 때문에 피드백이 음악 선생님이 아닌 소프트웨어로부터 제공된다는 것에 거부감이 있을 수 있음 |
