# An Overview of Automatic Piano Performance Assessment

- 원문: [An Overview of Automatic Piano Performance Assessment](https://www.scitepress.org/Papers/2022/111376/111376.pdf)
- 관련 기능: 자동 피아노 연주 평가 survey
- 선별 이유: 자동 피아노 연주 평가(APPA) 방법과 교육 피드백 접근을 검토하는 survey. 피아노 중심 MVP 설계 참고.

## 원문 클리핑

> 접근 메모: 서버가 PDF 바이너리만 반환해 본문 텍스트 인라인 클리핑에 실패했다(SciTePress, 2022). 아래는 출처 식별·메타정보 중심 요약이며, 인용 시 원문 PDF를 직접 확인할 것.

- SciTePress(2022, paper 111376) 게재 survey. 주제: **Automatic Piano Performance Assessment (APPA)**.
- 다루는 범위(survey 일반 구성): 평가 대상 차원(음정 정확도, 타이밍/리듬, 다이내믹, 페달링, 운지·기술, 표현/musicality), feature 추출(MIDI 기반 vs 오디오 기반), 모델링 접근(규칙/특징공학 vs 딥러닝), 데이터셋, 교육적 피드백(formative feedback) 적용.
- 시사점: 피아노를 첫 타깃 악기로 잡는 MVP에서, 어떤 평가 차원을 우선 자동화할지와 MIDI/오디오 입력 경로 선택의 비교 근거.

> 연관: 38번(객관 descriptor 분석), 25번(평가 루브릭 systematic review), 26번(SmartMusic 상용 채점), 41번(MatchMySound)과 함께 "평가 기준 + 알고리즘 + 상용 구현"을 삼각 검증.
